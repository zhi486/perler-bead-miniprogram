## Design Context

### Users
拼豆爱好者，经常在**手工店现场**快速查配色、确认图纸。使用场景：站立、单手操作、需要快速响应。核心任务：选图 → 看一眼配色方案 → 确认可行 → 导出。

**关键约束**：
- 操作要快，步骤要少，加载要有反馈
- 触摸目标要够大（单手拇指操作）
- 信息层级要清晰：图纸预览 > 颜色图例 > 参数设置

### Brand Personality
**温暖 · 利落 · 可靠**

像一个经验丰富但话不多的手艺师傅——专业、亲切、不啰嗦。不是甜美可爱的"手工博主"，也不是冷冰冰的工业工具。

- 温暖来自微妙的暖色调底色和友好的微交互，不来自花哨的装饰
- 利落来自克制的信息架构和清晰的排版层级
- 可靠来自快速响应和准确的色彩呈现

### Aesthetic Direction

**参考方向**：DeepSeek 式 UI —— 内容优先、排版驱动、装饰极简、焦点明确

**视觉基调**：
- **克制**：装饰降到最低，让拼豆图纸本身成为视觉焦点
- **扁平化**：减少卡片嵌套和阴影层级，用留白和细线分隔代替
- **单强调色**：用单一暖色系做功能强调，去掉渐变（当前橙→粉渐变偏"模板化"）
- **排版驱动**：用字号、字重、间距的对比建立信息层级，而非依赖卡片/色块

**反面参考（避免）**：
- 拼多多式的密集信息轰炸、大红大橙、弹窗叠加
- AI 模板三件套：暖奶油底(#faf8f5) + 卡片阴影 + 侧边色条
- 不必要的渐变、光晕、装饰性元素

**主题**：浅色模式（手工店环境通常光线充足，浅色更易读）

### Design Principles

1. **内容即是界面** —— 拼豆图纸是唯一的主角，UI 是安静的画框。减少卡片嵌套，用留白区隔内容区块。

2. **一眼看完** —— 首屏必须同时看到图纸预览和颜色图例。用户不需要滚动就能确认"这个图能不能做"。

3. **拇指友好** —— 所有交互控件 ≥ 44px 触摸区域。核心操作（选图、导出）放在屏幕下半部拇指热区。

4. **做过减法才算完成** —— 每个 UI 元素必须 justify 自己的存在。去掉一个装饰，看看是否依然清晰。Chanel 法则：出门前照镜子，摘掉一件配饰。

5. **颜色要诚实** —— UI 的强调色服务于功能（引导操作、标识状态），不与拼豆色卡的颜色"抢戏"。中性色微微偏暖（chroma ~0.005），不抢眼但能感受到温度。
